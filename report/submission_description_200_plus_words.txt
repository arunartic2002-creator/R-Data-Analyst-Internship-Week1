This Week 1 internship project focuses on data cleaning, preprocessing, and preliminary analysis using R. For the analysis, I selected the Titanic passenger training dataset from Kaggle because it contains a combination of numerical and categorical variables, missing values, and extreme observations, making it suitable for demonstrating a practical data-cleaning workflow. The dataset contains 891 passenger records and 12 original variables, including passenger class, sex, age, family information, fare, cabin, embarkation port, and survival status.

The project begins with data inspection using R functions such as dim(), str(), summary(), and missing-value checks. The missing-value analysis showed that Age, Cabin, and Embarked required attention. Missing Age values were handled using median imputation, while missing Embarked values were replaced with the mode. The Cabin column was removed because a very large proportion of its values were missing, making reliable imputation difficult for a preliminary analysis.

Numerical outliers were identified using the Interquartile Range (IQR) method. Instead of deleting observations, I capped extreme numerical values at the IQR boundaries to preserve the dataset size. Min-Max normalization was then applied to selected numerical variables. Categorical preprocessing included binary encoding of Sex and one-hot encoding of Embarked.

Finally, descriptive statistics, correlation analysis, and visualizations were generated to identify initial patterns. The preliminary findings indicate substantial differences in survival rates by sex and passenger class. The cleaned dataset, R script, analysis outputs, visualizations, and detailed DOCX report are included in the project repository. This project demonstrates a complete and reproducible foundation for further data analysis.
